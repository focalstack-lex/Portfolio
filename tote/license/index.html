Open source inside Tote

Tote is built with open source packages, each under its own license. The main ones:

  • Tauri, the app framework (MIT or Apache 2.0)
  • React and Zustand, the window's interface (MIT)
  • Lucide icons (ISC, with some icons from Feather under MIT)
  • Atkinson Hyperlegible Next, the typeface (SIL Open Font License 1.1)
  • SQLite through rusqlite, the file index (SQLite is public domain, rusqlite MIT)

The complete list, with every copyright notice and license text, is in third-party-notices.txt. The same file is installed next to Tote on your laptop as THIRD-PARTY-NOTICES.txt, together with LICENSE.txt.
